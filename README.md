# Doodle Identifier Using CNN

## Overview
This project is a lightweight deep learning application designed to recognize hand-drawn sketches. It combines convolutional neural networks (CNNs) with an interactive drawing interface to classify doodles into ten predefined categories. The system is fast, fun, and easy to use, offering an engaging demonstration of real-time image recognition using deep learning.

## Categories
The model is trained to recognize doodles from the following ten categories:
- Airplane
- Apple
- Banana
- Car
- Cat
- Duck
- Fish
- Hand
- House
- Soccer Ball

## Features
- Real-time doodle recognition.
- Built using MobileNetV1 for efficiency and low resource usage.
- Trained on a subset of the Google Quick, Draw! dataset.
- Simple, user-friendly interface for drawing and prediction.

## What I've Done
- **Model Development**: Implemented a CNN based on MobileNetV1 to handle simple image classification tasks.
- **Training**: Used a curated subset of the open-source doodles dataset from Google for model training.
- **User Interface**: Created a tool that allows users to draw directly on a canvas and get instant feedback on what the model predicts the drawing to be.

## Purpose
The goal of this project is to demonstrate how deep learning models can be used for creative, interactive tasks. It also highlights how efficient pre-trained models can be customized for specific use cases, making AI more accessible and responsive.

## Future Improvements
- Expand the number of recognizable categories.
- Improve accuracy through more data and model fine-tuning.
- Optimize UI for mobile use.
